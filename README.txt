Pichidhi Website Starter — Telugu instructions

ఈ ZIP లో:
- index.html: Username + Mobile Number form (demo)
- admin.html: Admin dashboard mock-up (demo)

ముఖ్యమైనది:
1. ప్రస్తుతం ఇది UI డెమో మాత్రమే. వివరాలు ఎక్కడికీ పంపబడవు లేదా సేవ్ కావు.
2. GitHub Pages static hosting మాత్రమే. నిజమైన visitor data சேமிக்க backend/database మరియు admin authentication అవసరం.
3. admin.html-ஐ பொதுவாக public site-ல் வைப்பது பாதுகாப்பானதல்ல; யாரும் திறக்கலாம்.
4. பயனரின் அனுமதி இல்லாமல் தனிப்பட்ட தகவல்களை சேகரிக்க வேண்டாம்.
5. Instagram password கேட்கவோ சேமிக்கவோ வேண்டாம்.

GitHub Pages-க்கு:
1. ZIP extract చేయండి.
2. మీ GitHub repository లో index.html ని upload/replace చేయండి.
3. admin.html కేవలం demo; నిజమైన secure dashboard గా ఉపయోగించకండి.
4. Settings > Pages లో main branch / root ఎంచుకుని Save చేయండి.
